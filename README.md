# Venkateswarlu Gudepu — personal academic website

Website: https://venkateshg808.github.io/

Updated from the November 2026 CV supplied by the site owner. Includes professional profile, education, experience, research, project roles, publications and manuscripts, awards, teaching, mentoring, standards, service.

## Files
- `index.html`: complete accessible, static content, including all 44 bibliography entries.
- `style.css`: responsive layout and light/dark themes.
- `script.js`: navigation, theme, category filters, search, and progressive publication display.
- `publications.json`: structured bibliography source for future edits. The page is rendered in HTML and does not fetch this file at runtime; update both together.
- `portrait.jpg`: profile photograph.
- `.nojekyll`: plain static publishing.

Published journals, conference/demo entries, under-review manuscripts, and reports have separate categories. Under-review work is not counted as published. Publication titles, author lists, and status follow the supplied CV; preprint links are labeled. Missing publication dates or links have not been invented.

## Publish and edit
GitHub Pages publishes from `main`, repository root. No build or dependencies are required. Open `index.html` locally to preview. Commit edits to `main` to publish updates.
